# Code of Conduct

## Our Commitment

We are committed to maintaining a respectful, professional, and safe collaboration environment for all project participants.

## Expected Behavior

- Be respectful and constructive
- Assume positive intent
- Accept feedback gracefully
- Focus on what is best for the community and project

## Unacceptable Behavior

- Harassment, trolling, insulting/derogatory comments
- Public or private abuse
- Publishing others' private information without explicit permission
- Any conduct that could reasonably be considered inappropriate in a professional setting

## Enforcement

Project maintainers are responsible for clarifying and enforcing this Code of Conduct and may take appropriate action in response to unacceptable behavior.

## Scope

This Code of Conduct applies in project spaces and in public spaces when an individual is representing the project or its community.

## Reporting

Report unacceptable behavior to project maintainers through a private channel.
